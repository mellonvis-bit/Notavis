✏️ Panduan Format Teks
Format Dasar
*teks* → Tebal
_teks_ → Miring
~teks~ → Coret
__teks__ → Garis Bawah
==teks== → Sorotan
`teks` → Kode
Judul
# Judul → Judul Besar
## Judul → Judul Sedang
### Judul → Judul Kecil
Elemen Teks
> teks → Kutipan
--- →
^teks^ → Tekssuperscript
,,teks,, → Tekssubscript
💡 Cara Pakai: Ketik simbol di awal dan akhir kata/kalimat, lalu tekan spasi atau Enter untuk mengaktifkan format. Contoh: tulis *kata penting* lalu tekan spasi.
